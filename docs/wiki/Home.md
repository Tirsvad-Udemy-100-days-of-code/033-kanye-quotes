# Kanye Says...

A small desktop app that shows a random Kanye West quote from the [Kanye Rest API](https://kanye.rest/) on every click. It is the solution to day 33 of Udemy's *100 Days of Code: The Complete Python Pro Bootcamp*.

![The app showing a quote](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/033-kanye-quotes/raw/branch/main/docs/images/quote-screen.png)

## At a glance

- Python 3.13 or newer, `tkinter`, no runtime dependencies.
- The assignment's function name `get_quote` is kept.
- Tests run offline with `python -m pytest`.
