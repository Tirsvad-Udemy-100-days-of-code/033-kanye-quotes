# Penggunaan

Dengan persekitaran aktif, mulakan aplikasi:

```bash
python -m kanye_quotes
```

atau:

```bash
kanye-quotes
```

## Apa yang anda lihat

Tetingkap "Kanye Says..." memaparkan belon ucapan dan gambar Kanye di bawahnya.

![Skrin permulaan](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/033-kanye-quotes/raw/branch/main/docs/images/start-screen.png)

Klik gambar Kanye. Teks pada belon diganti dengan petikan baharu daripada API. Klik lagi untuk petikan lain.

![Aplikasi memaparkan satu petikan](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/033-kanye-quotes/raw/branch/main/docs/images/quote-screen.png)

## Apabila sesuatu tidak berjalan

Jika API tidak dapat dicapai, belon memaklumkan bahawa petikan tidak dapat diambil. Aplikasi kekal terbuka; semak sambungan anda dan klik lagi.
