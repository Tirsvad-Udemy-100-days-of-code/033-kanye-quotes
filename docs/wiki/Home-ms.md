# Kanye Says...

Aplikasi desktop kecil yang memaparkan petikan rawak Kanye West daripada [Kanye Rest API](https://kanye.rest/) pada setiap klik. Ia ialah penyelesaian untuk hari ke-33 kursus Udemy *100 Days of Code: The Complete Python Pro Bootcamp*.

![Aplikasi memaparkan satu petikan](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/033-kanye-quotes/raw/branch/main/docs/images/quote-screen.png)

## Halaman

- [Bermula](Getting-Started-ms): pasang Python, cipta `.venv`, pasang projek
- [Penggunaan](Usage-ms): jalankan aplikasi dan apa yang anda lihat
- [Pembangunan](Development-ms): ujian, linting dan Doxygen
- [Seni bina](Architecture-ms): lapisan kod dan sebab `urllib` menggantikan `requests`

## Sepintas lalu

- Python 3.13 atau lebih baharu, `tkinter`, tiada kebergantungan semasa larian.
- Nama fungsi tugasan `get_quote` dikekalkan.
- Ujian berjalan tanpa internet dengan `python -m pytest`.
