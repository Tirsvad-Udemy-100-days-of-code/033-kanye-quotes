# Usage

With the environment active, start the app:

```bash
python -m kanye_quotes
```

or:

```bash
kanye-quotes
```

## What you see

The window "Kanye Says..." shows a speech bubble and the Kanye picture below it.

![The start screen](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/033-kanye-quotes/raw/branch/main/docs/images/start-screen.png)

Click the Kanye picture. The text on the bubble is replaced by a new quote from the API. Click again for another one.

![The app showing a quote](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/033-kanye-quotes/raw/branch/main/docs/images/quote-screen.png)

## When something goes wrong

If the API cannot be reached, the bubble says that no quote could be fetched. The app stays open; check your connection and click again.
