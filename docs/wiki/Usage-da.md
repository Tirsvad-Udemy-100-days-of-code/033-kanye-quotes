# Brug

Start appen, mens miljøet er aktivt:

```bash
python -m kanye_quotes
```

eller:

```bash
kanye-quotes
```

## Hvad du ser

Vinduet "Kanye Says..." viser en taleboble og Kanye-billedet under den.

![Startskærmen](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/033-kanye-quotes/raw/branch/main/docs/images/start-screen.png)

Klik på Kanye-billedet. Teksten i boblen bliver erstattet af et nyt citat fra API'et. Klik igen for et nyt.

![Appen viser et citat](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/033-kanye-quotes/raw/branch/main/docs/images/quote-screen.png)

## Når noget går galt

Hvis API'et ikke kan nås, siger boblen, at der ikke kunne hentes et citat. Appen forbliver åben; tjek din forbindelse, og klik igen.
